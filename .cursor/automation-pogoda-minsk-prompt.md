## 1. Погода (общая для всех)

Узнай погоду по Минску (Беларусь):

- текущая: температура, ощущается как, условия, ветер, влажность, вероятность дождя
- на день вперёд (до вечера): как изменится температура, осадки, ветер, когда вероятнее дождь

Один общий блок погоды

## 2. Советы по одежде

## 3. Новости

Собери 3-4 свежих новостных тезисов на момент запуска (мировые + Беларусь/регион, если есть).
Требования:

- только свежие события
- не военные новости
- больше упор на технологические новости
- две новости про игры
- тезисно, 1 строка на тезис
- без воды, без ссылок-простыней, без выдумок
- если источник неясен — не включай

## 4. Английский (уровень A2–B1)

Сделай **ровно 5 пар «слово + фраза»** — ни больше, ни меньше. Уровень CEFR A2–B1 (не A1, не B2+).

Каждая из 5 пар обязательно содержит:

1. одно английское слово;
2. краткий перевод слова на русский (1–3 слова);
3. одну короткую фразу-пример с этим словом на английском (5–12 слов, A2–B1);
4. перевод фразы на русский.

Требования:

- слова полезные в быту, работе, новостях, погоде, путешествиях — без узкой сленговой лексики;
- каждый запуск — новый набор из 5 пар, не повторяй слова с прошлых дней без необходимости;
- фразы грамматически корректные, без идиом уровня C1;
- при желании 1–2 пары можно мягко связать с темой дня (погода/новости), остальные — нейтральные.

Перед отправкой в Telegram проверь: в блоке «🇬🇧 Английский A2–B1» есть пункты **только** 1️⃣ 2️⃣ 3️⃣ 4️⃣ 5️⃣, у каждого — слово, перевод, фраза, перевод фразы. Если пар меньше 5 — дополни, не отправляй неполный блок.

## 5. Цитата

В самом конце добавь одну хорошую цитату:

- короткая, ёмкая, с автором
- лучше по настроению дня/погоде или универсальная мудрая
- не банальный мотивационный штамп и не политика
- каждый раз старайся другую цитату

## 6. Оформление для Telegram (обязательно)

Сообщение должно быть живым и удобным для чтения в TG — НЕ серое полотно текста.
Правила:

- используй эмодзи как маркеры секций и пунктов
- короткие абзацы, пустые строки между блоками
- не больше 1–2 эмодзи на строку
- без markdown-звёздочек **, без HTML, без кода — обычный текст + эмодзи
- цифры и факты выделяй эмодзи, а не стеной текста

## 7. Отправка

Отправь через Telegram Bot API. Токен и чат — из переменных окружения `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`.
POST https://api.telegram.org/bot{TELEGRAM_BOT_TOKEN}/sendMessage
JSON:
{
  "chat_id": "{TELEGRAM_CHAT_ID}",
  "text": "<сообщение>",
  "disable_web_page_preview": true
}
Не печатай токен и chat_id в финальном ответе.

В конце внутреннего отчёта — коротко: отправлено, температура сейчас, вероятность дождя, число тезисов, **число английских пар (должно быть 5)**.
